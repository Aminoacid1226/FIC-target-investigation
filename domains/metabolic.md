# 治疗领域配置：代谢疾病（Metabolic）

> 覆盖糖尿病、肥胖、血脂异常、脂肪肝/非酒精性脂肪性肝炎、代谢综合征等

---

## 1. 优先疾病与靶点

| 疾病 | 优先靶点方向 | 依据 |
|------|-------------|------|
| **2型糖尿病** | GLP-1R, GCGR, FGF21, SGLT2, SIRT1/6, PGC-1α, AMPK, HMGCR 调控 | 当前有成熟市场但仍有机制空间 |
| **肥胖** | MC4R, GIPR/GLP-1R 双靶点, FTO, BDNF, Orexin, Lipin1/2 | 减重市场爆发，急需新分子 |
| **NASH/NAFLD** | FXR, PPARα/γ/δ, ACC1/2, SCD1, DGAT1/2, MTHFR, PCSK9, APOB | 未满足需求巨大，缺乏有效药物 |
| **血脂异常** | PCSK9, ANGPTL3/4/8, APOC3, LPL, LDLR, SREBP2, HMGCR | LDL-C 之外的新靶点 |
| **糖原累积症** | G6Pase, PEPCK, F1,6BPase | 罕见病，孤儿药激励 |
| **线粒体病** | PGC-1α, AMPK, mtDNA 稳定, UPRmt | 罕见，急需 FIC |

## 2. 代谢靶点分类体系

### 2.1 代谢激素/受体通路

**已充分占领：**
- GLP-1R（大量肽类 + 小分子）
- GIPR（与 GLP-1R 联用药）
- GCGR
- SGLT2（已上市多个）
- MC4R（有进展但选择性困难）

**新兴高潜力：**
- FGF21（肝/脂代谢调节）
- FGF19/21 受体（FGFR4）
- Orexin 受体（中枢代谢）
- TGR5（胆汁酸受体）
- GPBAR1（胆汁酸受体）
- 生长激素受体（GHR）

### 2.2 能量代谢通路

**糖代谢：**
- AMPK（α1/α2/β1/β2/γ1/γ2/γ3）
- SIRT1/SIRT3/SIRT6（选择性激活剂）
- PGC-1α（转录共激活因子）
- mTORC1/C2（雷帕霉素耐药 vs 敏感）
- 糖酵解关键酶（HK2, PKM2, PFKM）

**脂代谢：**
- ACC1/2（乙酰辅酶 A 羧化酶，合成脂肪酸必需）
- FASN（脂肪酸合成酶）
- SCD1（硬脂酰辅酶 A 去饱和酶-1）
- DGAT1/2（甘油三酯合成）
- HMGCR（他汀靶点）
- LXRα/β（肝 X 受体）
- PPARα/γ/δ（过氧化物酶体增殖物激活受体）

**线粒体代谢：**
- 线粒体复合体 I–V
- mtDNA 维护（TFAM）
- 线粒体膜电位（UCP1/2/3）
- 线粒体 ROS 清除
- UPRmt（线粒体未折叠蛋白应答）

### 2.3 肝脏特异性靶点

**NASH 关键通路：**
- 脂肪从头合成（De novo lipogenesis, DNL）
- 脂肪酸 β-氧化
- 氧化应激（ROS 产生/清除）
- 炎症通路（NF-κB, JNK）
- 纤维化（HSC 激活, TGFβ）

### 2.4 中枢代谢靶点

- 下丘脑 POMC/CART（饱食信号）
- 下丘脑 NPY/AgRP（饥饿信号）
- 蓝斑去甲肾上腺素（能量消耗）
- 杏仁核（代谢应激应答）
- 脑-肝轴（GLP-1R 中枢作用）

## 3. 代谢特别评估维度

### 3.1 靶器官特异性

| 靶点类型 | 评估重点 |
|---------|---------|
| 肝脏靶点 | 肝脏富集表达、首过代谢利用、肠道/肝脏双重靶向 |
| 脂肪组织靶点 | 白色脂肪 vs 棕色脂肪选择性 |
| 中枢靶点 | 血脑屏障穿透、中枢毒性、体重影响 |
| 肠道靶点 | 肠道代谢稳定性、局部作用 vs 全身吸收 |

### 3.2 表型可测量性

- 是否有可靠的替代终点（HbA1c, LDL-C, 体重）
- 非侵入性检测方法（血糖、血脂、肝酶）
- 临床可操作性（是否需要复杂检测）

### 3.3 长期安全性

- 代谢靶点的长期毒性（如 PPARγ 的水肿/体重增加）
- 心血管风险（如罗格列酮事件）
- 骨骼影响（如 SGLT2 的骨折风险）
- 肝肾耐受性

### 3.4 商业化路径

| 策略 | 适用场景 |
|------|---------|
| 罕见代谢病切入 | 孤儿药 → 扩展至常见病 |
| 新机制差异化 | 比 GLP-1R 更好的减重/代谢改善 |
| 联合用药 | 与二甲双胍、GLP-1R、SGLT2 联用 |
| 生物标志物分层 | 代谢亚型精准匹配 |

## 5. 代谢常见淘汰原因 Top 10

| 排名 | 淘汰原因 |
|------|---------|
| 1 | 靶点已有同类产品获批或 III 期 |
| 2 | 长期安全性风险（心血管、肝肾毒性） |
| 3 | 无明确 pocket 或已充分开发 |
| 4 | 靶点表达广泛，选择性困难 |
| 5 | Big Pharma 已大量布局 |
| 6 | 临床终点不明确 |
| 7 | 药代特性差（半衰期过短/过长） |
| 8 | 与 GLP-1R 联用无协同效应 |
| 9 | 靶点生物学证据仅 GWAS 关联 |
| 10 | 市场已被 GLP-1R 类药物高度占领 |
