# 治疗领域配置：神经系统疾病（Neurology）

> 覆盖帕金森、阿尔茨海默、癫痫、偏头痛、多发性硬化、抑郁等

---

## 1. 优先疾病与靶点

| 疾病 | 优先靶点方向 | 依据 |
|------|-------------|------|
| **帕金森病** | LRRK2, GBA, SNCA, Parkin, PINK1, DJ-1 | 基因突变明确，有家族性靶点 |
| **阿尔茨海默病** | BACE1, PSEN1/2, TREM2, APOEε4, tau 病理相关 | 病理机制存在争议，急需新靶点 |
| **癫痫** | Nav1.1 (SCN1A), Nav1.6 (SCN8A), KCNQ2/3, mGluR7, ADK | 通道病为主 |
| **偏头痛** | CGRP(R), 5-HT1B/1D, 5-HT1F, PACAP | 急性/预防治疗均有空间 |
| **抑郁/焦虑** | mGluR5, 5-HT7, NK1, OX1/2R, TrkB, mTORC1 | 新机制抗抑郁 |
| **卒中/神经保护** | PARP1, NMDAR 亚基, 氧化应激靶点, TSPO | 急性事件干预时间窗 |
| **疼痛（神经病理性）** | Nav1.7 (SCN9A), TRPV1/4, 5-HT2A, P2X7, NaV1.8 | 选择性钠通道 |
| **肌萎缩侧索硬化** | C9orf72, TARDBP, FUS, SOD1 | 罕见病，孤儿药 |

## 2. 神经靶点分类体系

### 2.1 中枢穿透性（最大挑战）

**血脑屏障（BBB）穿透标准：**
- LogD 2–3（BBB 最优化范围）
- MW < 450
- 低 P-gp 底物可能性
- 低血清蛋白结合（fU > 5%）
- 无带电基团（中性分子优先）

**中枢特化靶点类型：**
- GPCR（小分子，可穿透）
- 离子通道（小分子，可穿透）
- 胞内激酶（小分子，可穿透）
- 神经递质转运体（小分子，可穿透）
- 分泌蛋白（需要基因治疗/抗体工程）

### 2.2 神经退行性疾病靶点

**蛋白稳态相关：**
- Alpha-synuclein（路易体病）
- Tau（tauopathies, AD）
- Amyloid-β（AD）
- TDP-43（ALS, FTD）
- FUS（ALS）
- Huntingtin（亨廷顿舞蹈症）
- SOD1（ALS）

**线粒体功能：**
- LRRK2（激酶 + GTPase，帕金森）
- Parkin（E3 泛素连接酶）
- PINK1（线粒体丝氨酸/苏氨酸激酶）
- DJ-1（氧化应激保护）
- GBA（溶酶体酶，帕金森风险因子）

**先天免疫：**
- TREM2（小胶质细胞受体，AD 风险因子）
- RAGE（Aβ 受体）
- CSF1R（小胶质细胞存活）

### 2.3 离子通道病靶点

| 通道 | 疾病 | 选择性策略 |
|------|------|-----------|
| Nav1.1 | Dravet 综合征 | 选择性沉默突变体 |
| Nav1.7 | 家族性痛症/癫痫 | 脊髓背角选择性 |
| Nav1.6 | 癫痫 | 突触末端选择性 |
| KCNQ2/3 | 良性新生儿癫痫 | M 电流增强 |
| Cav2.1/2.2 | 偏头痛 | P/Q/N 型选择性 |
| GLUA1-4 | 癫痫 | AMPA 受体减敏剂 |

## 3. 神经特别评估维度

### 3.1 血脑屏障穿透

**预测参数：**
| 参数 | 理想范围 | 说明 |
|------|---------|------|
| LogD | 2.0–3.0 | 中枢最优化 |
| MW | < 450 | 过大难穿透 |
| PSA | < 90 Å² | 过大多氢鍵 |
| HBA | < 8 | 降低多氢鍵受体 |
| HBD | < 2 | 降低多氢鍵供体 |
| pKa | 6.5–8.0 | 中性分子比例高 |
| P-gp substrate | 否 | 避免被外排 |
| IC50 CSF/IC50 plasma | > 0.1 | 脑内有效浓度 |

### 3.2 中枢毒性

- 作用机制的 CNS 安全性（如 mGluR 激动剂 vs 拮抗剂）
- 认知功能影响（工作记忆、注意力、执行功能）
- 运动功能影响（共济失调、震颤）
- 情绪/行为改变
- 癫痫诱发风险
- QT 延长

### 3.3 疾病修饰治疗（DMT）vs 症状治疗

| 类型 | 代表 | 商业价值 |
|------|------|---------|
| **DMT（延缓疾病进展）** | 阿尔茨海默 aducanumab（有争议）、帕金森 LRRK2 抑制剂 | 极高（治愈级定价） |
| **症状治疗** | 偏头痛 CGRP 抑制剂、癫痫 NaV 通道抑制剂 | 中高（长期维持） |

### 3.4 临床终点

| 疾病 | 终点类型 | 难点 |
|------|---------|------|
| 阿尔茨海默 | 认知量表（MMSE, ADAS-Cog）+ 生物标志物 | 临床终点困难、生物标志物争议 |
| 帕金森 | UPDRS 量表 + 生物标志物 | 症状波动大 |
| 偏头痛 | 急性发作减少 + 预防频率 | 患者报告为主 |
| 癫痫 | 发作频率减少 ≥ 50% | 安慰剂效应高 |
| 疼痛 | NRS 评分减少 ≥ 30% | 主观、安慰剂效应高 |

## 5. 神经常见淘汰原因 Top 10

| 排名 | 淘汰原因 |
|------|---------|
| 1 | BBB 穿透性差，脑内无法达到有效浓度 |
| 2 | 中枢毒性风险高（认知/运动/情绪副作用） |
| 3 | 靶点已有同类产品获批或 III 期 |
| 4 | 无明确 pocket 或选择性困难 |
| 5 | Big Pharma 已大量布局 |
| 6 | 临床终点设计困难，FDA 不接受 |
| 7 | 靶点生物学证据仅 GWAS 关联 |
| 8 | 药代特性差（半衰期过短/过长） |
| 9 | 靶点表达广泛，选择性困难 |
| 10 | 市场被现有药物高度占领 |
